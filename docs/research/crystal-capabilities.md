# Crystal 语言能力实证（本机 Crystal 1.22.1, Windows ucrt64）

- 探针环境：`C:\msys64\ucrt64\bin\crystal.exe`，`Crystal 1.22.1 [23828b0a40] (2026-10-23), LLVM 23.1.3, Default target x86_64-w64-windows-gnu`（`crystal --version`）

GC（Boehm/GC.stats/GC.collect/稳态零分配可测性） | **部分验证**：`GC.stats` 可用，返回 `GC::Stats`，字段 `heap_size/free_bytes/unmapped_bytes/bytes_since_gc/total_bytes` 类型均为 `UInt64`；`GC.collect` 后 `bytes_since_gc` 由 `74128` 变为 `0`（行为可观测）。稳态整数循环（`GC.disable` 后 1,000,000 次累加）前后 `bytes_since_gc=0, total_bytes=75040` 不变，表明该循环在本机样本中“可测出零分配”。“默认是否 Boehm”**未能从运行时直接证实实现名**：`crystal eval` 得 `flag?(:gc_boehm)=false`、`flag?(:gc_none)=false`，`GC.responds_to?(:malloc)=true`（仅侧证 GC 接口存在）。 | 本机实测 + 官方 API 文档 | 命令：`crystal run %TEMP%\tessell-probe\probe_gc.cr`；关键输出：`GC.stats: GC::Stats(@heap_size=262144, @free_bytes=114688, @unmapped_bytes=0, @bytes_since_gc=73520, @total_bytes=73520)` / `before bytes_since_gc=74128` → `after bytes_since_gc=0` / `steady_before total_bytes=75040` → `steady_after total_bytes=75040`。命令：`crystal eval 'p {{ flag?(:gc_boehm) }}; p {{ flag?(:gc_none) }}'` → `false`/`false`；`crystal eval 's=GC.stats; puts s.heap_size.class ...'` → 五字段均 `UInt64`。脚本：`%TEMP%\tessell-probe\probe_gc.cr`。文档：https://crystal-lang.org/api/1.22.1/GC.html 、https://crystal-lang.org/api/1.22.1/GC/Stats.html |
